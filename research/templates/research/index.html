// Process

How the agent works

01 —
📦
Clone the repository
Shallow clone (depth=1) into local storage. Subsequent calls fetch + reset — no re-clone on repeat questions.
02 —
🗄️
Read prior findings
First tool call is always get_previous_findings. If earlier sessions found relevant code, the agent builds on them instead of re-exploring.
03 —
🔍
Explore the code
list_files → search_code → read_file. Calls save_finding for every relevant location discovered.
04 —
✅
Return a cited answer
Final answer cites specific file paths and line numbers. All tool calls persisted. Token usage tracked. Session stored for future queries.

// REST API

Three endpoints under /api/

POST /api/sessions/ Start a research session

Accepts a GitHub URL and a question. Runs the agent loop synchronously (20–90 s for a small repo). Returns the full session with tool calls, findings, and final answer.

bash 
curl -s -X POST http://localhost:8000/api/sessions/ \
  -H "Content-Type: application/json" \
  -d '{
    "repo_url": "https://github.com/psf/requests",
    "question": "How does requests handle SSL certificate verification?"
  }' | jq .
GET /api/sessions/<uuid>/ Retrieve a session

Returns a full session detail including all persisted tool calls and findings.

bash 
curl -s \
  http://localhost:8000/api/sessions/8a4b1c2d-0000-0000-0000-000000000001/ \
  | jq '{status, iterations, final_answer}'
GET /api/repositories/<id>/sessions/ List sessions for a repo

Returns paginated list of all sessions for a repository, newest first. Page size: 20.

bash 
curl -s \
  "http://localhost:8000/api/repositories/1/sessions/?page=1" \
  | jq '.results[] | {status, question_preview}'
